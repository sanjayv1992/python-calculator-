# Crop Diseases

Disease identification and management: symptoms, favourable conditions, disease cycles, and integrated management for fungal, bacterial, and viral diseases.

## What belongs here

- Disease identification guides with field symptoms
- IPM/IDM schedules per crop
- Advisories for outbreak years

Add files as `.md`/`.txt` (indexed as text sources), `.pdf` (uploaded), or list
web pages in a `urls.txt` file (one URL per line). Then run
`python scripts/index_knowledge.py` from the repository root — the import is
idempotent, so re-running only adds new documents.

## Trusted sources for this domain

- ICAR-NCIPM advisories
- SAU plant pathology extension bulletins
- State agriculture department disease alerts

Only add documents from verified official sources — see
[docs/knowledge-sources.md](../../docs/knowledge-sources.md) for the full
sourcing policy.
