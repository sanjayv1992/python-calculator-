# Crops

Crop-wise production guides: varieties, sowing windows, spacing, package of practices for cereals, pulses, oilseeds, vegetables, and fruits.

## What belongs here

- Crop production guides (state package of practices)
- Variety release notifications and seed catalogues
- High-yield cultivation technical bulletins

Add files as `.md`/`.txt` (indexed as text sources), `.pdf` (uploaded), or list
web pages in a `urls.txt` file (one URL per line). Then run
`python scripts/index_knowledge.py` from the repository root — the import is
idempotent, so re-running only adds new documents.

## Trusted sources for this domain

- ICAR crop institutes (IIWBR, IIRR, IIMR, etc.)
- State Agricultural University package-of-practices manuals
- Krishi Vigyan Kendra (KVK) crop bulletins

Only add documents from verified official sources — see
[docs/knowledge-sources.md](../../docs/knowledge-sources.md) for the full
sourcing policy.
