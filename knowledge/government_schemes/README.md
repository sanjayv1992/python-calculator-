# Government Schemes

Central and state schemes for farmers: benefits, eligibility, required documents, and application processes (PM-KISAN, PMFBY, KCC, subsidies, etc.).

## What belongs here

- Official scheme guidelines (PDF)
- Application process notifications
- State-specific subsidy circulars

Add files as `.md`/`.txt` (indexed as text sources), `.pdf` (uploaded), or list
web pages in a `urls.txt` file (one URL per line). Then run
`python scripts/index_knowledge.py` from the repository root — the import is
idempotent, so re-running only adds new documents.

## Trusted sources for this domain

- Ministry of Agriculture & Farmers Welfare scheme portals
- State agriculture department circulars
- PM-KISAN / PMFBY official guidelines

Only add documents from verified official sources — see
[docs/knowledge-sources.md](../../docs/knowledge-sources.md) for the full
sourcing policy.
