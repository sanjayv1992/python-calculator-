# Fertilizers

Nutrient management: fertilizer products, recommended doses by crop and soil-test value, application timing and methods, deficiency symptoms.

## What belongs here

- Fertilizer recommendation tables (soil-test based)
- Product labels and nutrient contents
- Micronutrient management guides

Add files as `.md`/`.txt` (indexed as text sources), `.pdf` (uploaded), or list
web pages in a `urls.txt` file (one URL per line). Then run
`python scripts/index_knowledge.py` from the repository root — the import is
idempotent, so re-running only adds new documents.

## Trusted sources for this domain

- Soil-test crop-response (STCR) recommendations
- SAU soil science bulletins
- Fertilizer company label leaflets

Only add documents from verified official sources — see
[docs/knowledge-sources.md](../../docs/knowledge-sources.md) for the full
sourcing policy.
