# Insect Pests

Insect pest identification and management: life cycles, damage symptoms, economic threshold levels (ETL), and IPM options.

## What belongs here

- Pest identification cards
- ETL tables per crop
- IPM packages and pheromone-trap protocols

Add files as `.md`/`.txt` (indexed as text sources), `.pdf` (uploaded), or list
web pages in a `urls.txt` file (one URL per line). Then run
`python scripts/index_knowledge.py` from the repository root — the import is
idempotent, so re-running only adds new documents.

## Trusted sources for this domain

- ICAR-NCIPM pest advisories
- SAU entomology bulletins
- KVK pest surveillance reports

Only add documents from verified official sources — see
[docs/knowledge-sources.md](../../docs/knowledge-sources.md) for the full
sourcing policy.
