# Plant Growth Regulators (PGRs)

Registered plant growth regulators: purpose, crop, registered use, timing, dose,
and safety. Only label-accurate, registered information belongs here.

## What belongs here

- Registered PGR label claims (e.g. for lodging, fruit set, ripening)
- SAU/ICAR recommendations on PGR use
- Safety and pre-harvest interval information

Add files with full frontmatter metadata (see `knowledge/README.md`), then run
`python scripts/build_catalog.py`.

## Trusted sources for this domain

- CIB&RC registered label claims
- SAU crop physiology / agronomy bulletins

Only add documents from verified official sources — see
[docs/knowledge-sources.md](../../docs/knowledge-sources.md).
