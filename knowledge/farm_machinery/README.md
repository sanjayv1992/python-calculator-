# Farm Machinery

Farm implements and machinery: purpose, suitable operations, safe use, and
subsidy schemes (e.g. SMAM). Practical guidance for smallholder mechanisation.

## What belongs here

- Implement guides (seed drill, rotavator, happy seeder, transplanter, sprayer)
- Safe operation and maintenance notes
- Machinery subsidy scheme documents (SMAM, CHC)

Add files with full frontmatter metadata (see `knowledge/README.md`), then run
`python scripts/build_catalog.py`.

## Trusted sources for this domain

- SMAM / agrimachinery.nic.in scheme documents
- ICAR-CIAE and SAU farm-machinery bulletins

Only add documents from verified official sources — see
[docs/knowledge-sources.md](../../docs/knowledge-sources.md).
