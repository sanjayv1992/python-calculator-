# Nutrient Deficiency

Crop nutrient-deficiency identification and correction: visual symptoms, confirmatory
soil/tissue tests, and corrective practices for macro and micro nutrients.

## What belongs here

- Deficiency symptom guides (N, P, K, S, Zn, Fe, B, etc.)
- Soil Health Card interpretation for deficiencies
- Foliar/soil correction recommendations

Add files with full frontmatter metadata (see `knowledge/README.md`), then run
`python scripts/build_catalog.py`.

## Trusted sources for this domain

- ICAR-IISS and SAU soil science bulletins
- Soil Health Card scheme material
- KVK nutrient-management advisories

Only add documents from verified official sources — see
[docs/knowledge-sources.md](../../docs/knowledge-sources.md).
