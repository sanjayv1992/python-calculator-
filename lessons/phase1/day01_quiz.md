# Day 1 Quiz — Variables & Data Types

## PART A: Multiple Choice (MCQ)

**Q1.** Python mein `kisan_naam = "Ramesh"` — yahan `kisan_naam` kya hai?
- A) Function
- B) Variable ✅
- C) Loop
- D) Class

**Q2.** `14.5` ka data type kya hoga?
- A) int
- B) str
- C) float ✅
- D) bool

**Q3.** Kaunsa variable name **GALAT** (invalid) hai?
- A) `fasal_price`
- B) `_rate`
- C) `price2024`
- D) `2fasal` ✅

**Q4.** `type("Gehun")` ka output kya hoga?
- A) `<class 'int'>`
- B) `<class 'str'>` ✅
- C) `<class 'float'>`
- D) `<class 'bool'>`

**Q5.** `True` aur `False` kaunsa data type hai?
- A) str
- B) int
- C) float
- D) bool ✅

## PART C: Code Output Batao

```python
z = "Kisan"
flag = True
```

```
10

```

## PART D: Error Dhundho

```python
farmer name = "Suresh"    # Line 1
```
